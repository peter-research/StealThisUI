# StealThisUI — English

[← Back to the main README](./README.md) · [Contributing](./CONTRIBUTING.md)

**Copy-ready UI components for modern web projects.**

StealThisUI is a growing collection of reusable interface components, visual effects, and interaction patterns for developers who want to build faster without starting from scratch.

## Explore the library

| Category | What you can find |
| --- | --- |
| Buttons & controls | Calls to action, toggles, like buttons, and compact actions |
| Cards & content | Information cards, profiles, statistics, and content blocks |
| Forms & inputs | Fields, selectors, and form patterns |
| Backgrounds | Gradients, grids, textures, and decorative surfaces |
| Navigation & overlays | Menus, docks, notifications, and utility UI |
| Widgets & effects | Progress indicators, loaders, and small interactions |

Browse the [components directory](./components).

## Quick start

1. Open a component file in `components/`.
2. Check its exports, props, imports, styling assumptions, and dependency notes.
3. Copy it into your application.
4. Adapt it to your design system and test it in context.

Most components use React and TypeScript, but requirements may differ by file. Use the actual export and import path shown in the source.
