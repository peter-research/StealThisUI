# StealThisUI — Español

[← Volver al README principal](./README.md) · [Guía de contribución](./CONTRIBUTING.md)

**Componentes de interfaz listos para copiar en proyectos web modernos.**

StealThisUI reúne componentes reutilizables, efectos visuales y patrones de interacción para crear interfaces más rápido, sin empezar desde cero.

## Explora la biblioteca

| Categoría | Qué encontrarás |
| --- | --- |
| Botones y controles | Llamadas a la acción, interruptores, botones de «me gusta» y acciones rápidas |
| Tarjetas y contenido | Tarjetas informativas, perfiles, estadísticas y bloques de contenido |
| Formularios | Campos, selectores y patrones de formularios |
| Fondos | Degradados, cuadrículas, texturas y superficies decorativas |
| Navegación y ventanas | Menús, docks, notificaciones y elementos auxiliares |
| Widgets y efectos | Indicadores de progreso, cargadores y pequeñas interacciones |

Explora el directorio [components](./components).

## Inicio rápido

1. Abre un archivo dentro de `components/`.
2. Comprueba sus exportaciones, propiedades, imports, estilos y dependencias.
3. Cópialo en tu aplicación.
4. Adáptalo a tu sistema de diseño y pruébalo en contexto.

La mayoría de los componentes usan React y TypeScript, pero los requisitos pueden variar. Usa la ruta de importación y el nombre exportado que aparezcan en el archivo.

## Contribuir

Se aceptan componentes nuevos, correcciones, mejoras de accesibilidad y diseño adaptable, ejemplos y documentación. Lee la [guía de contribución](./CONTRIBUTING.md) antes de proponer cambios.
