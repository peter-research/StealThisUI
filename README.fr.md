# StealThisUI — Français

[← Retour au README principal](./README.md) · [Guide de contribution](./CONTRIBUTING.md)

**Des composants d’interface prêts à copier pour les projets web modernes.**

StealThisUI rassemble des composants réutilisables, des effets visuels et des modèles d’interaction pour créer plus vite sans repartir de zéro.

## Explorer la bibliothèque

| Catégorie | Contenu |
| --- | --- |
| Boutons et contrôles | Appels à l’action, interrupteurs, boutons « j’aime » et actions rapides |
| Cartes et contenu | Cartes d’information, profils, statistiques et blocs de contenu |
| Formulaires | Champs, sélecteurs et modèles de formulaires |
| Arrière-plans | Dégradés, grilles, textures et surfaces décoratives |
| Navigation et fenêtres | Menus, docks, notifications et éléments utilitaires |
| Widgets et effets | Indicateurs de progression, chargements et petites interactions |

Parcours le dossier [components](./components).

## Démarrage rapide

1. Ouvre un fichier dans `components/`.
2. Vérifie ses exports, propriétés, imports, styles et dépendances.
3. Copie le composant dans ton application.
4. Adapte-le à ton système de design et teste-le dans son contexte.

La plupart des composants utilisent React et TypeScript, mais les exigences peuvent varier. Utilise le chemin d’import et le nom exporté réellement présents dans le fichier.

## Contribuer

Les nouveaux composants, corrections, améliorations d’accessibilité, ajustements responsive, exemples et améliorations de documentation sont les bienvenus. Lis le [guide de contribution](./CONTRIBUTING.md) avant de proposer une modification.
