## English

StealThisUI is a growing collection of reusable interface components, visual effects, and interaction patterns. It is designed for developers who want to move quickly without starting every UI element from scratch.

### Explore the library

| Category | What you can find |
| --- | --- |
| **Buttons & controls** | Calls to action, toggles, likes, and compact actions |
| **Cards & content** | Value cards, profiles, product layouts, and content blocks |
| **Forms & inputs** | Fields, selectors, and form patterns |
| **Backgrounds** | Gradients, grids, textures, and decorative surfaces |
| **Navigation & overlays** | Menus, docks, notifications, and utility UI |
| **Widgets & effects** | Progress indicators, loaders, clocks, and small interactions |

Browse the [components directory](./components) and copy the component that best fits your project.

### Quick start

1. Open a component file in the components directory.
2. Copy it into your application.
3. Check its imports, props, styling assumptions, and any dependency notes.
4. Adapt the markup and styles to your design system.

Most components use React and TypeScript. Styling and dependencies can vary by component, so always check the source file before using it.

Example:

    import { LikeButton } from "./components/buttons/like-button";

    export function Example() {
      return (
        <main className="p-6">
          <LikeButton />
        </main>
      );
    }

> **Note:** Import paths and exports may differ between components. Use the exact exported name and path shown in the file you copy.

### Add a component

- Use a clear, kebab-case filename and the closest matching category.
- Keep components focused, reusable, responsive, and accessible.
- Support keyboard interaction and visible focus states for interactive controls.
- Avoid unnecessary dependencies and document any that are required.
- Test the component in a real app; do not submit placeholders.
- Preserve third-party licenses and attribution when adapting existing work.

### Licensing

Check the repository's license and any component-specific notices before reusing or redistributing code. Adapted third-party components may have separate attribution or license requirements. Do not assume every file has identical licensing terms.

### Contributing

Bug fixes, accessibility improvements, responsive refinements, examples, documentation, and original components are all welcome. Small, complete, verifiable improvements are more useful than large batches of untested files.
