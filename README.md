## Quick start

1. Browse the `components/` directory.
2. Open a component and inspect its exports, props, styles, imports, and dependency notes.
3. Copy it into your application and adapt it to your design system.
4. Install any dependencies explicitly required by that component.

Most components use React and TypeScript. Requirements can differ, so check each file before integrating it.

## Project principles

- Practical implementations over placeholders.
- Responsive layouts and accessible interactions.
- Clear component names and category folders.
- Minimal dependencies and transparent requirements.
- Respect for original authors, licenses, and attribution.
