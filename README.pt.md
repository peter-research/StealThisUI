# StealThisUI — Português

[← Voltar ao README principal](./README.md) · [Guia de contribuição](./CONTRIBUTING.md)

**Componentes de interface prontos para copiar em projetos web modernos.**

StealThisUI reúne componentes reutilizáveis, efeitos visuais e padrões de interação para ajudar a criar interfaces com mais rapidez, sem começar do zero.

## Explore a biblioteca

| Categoria | O que você encontra |
| --- | --- |
| Botões e controles | Chamadas para ação, alternadores, botões de curtir e ações compactas |
| Cards e conteúdo | Cards informativos, perfis, estatísticas e blocos de conteúdo |
| Formulários | Campos, seletores e padrões de formulários |
| Planos de fundo | Gradientes, grades, texturas e superfícies decorativas |
| Navegação e sobreposições | Menus, docks, notificações e elementos utilitários |
| Widgets e efeitos | Indicadores de progresso, carregadores e pequenas interações |

Explore a pasta [components](./components).

## Começo rápido

1. Abra um arquivo em `components/`.
2. Confira exports, propriedades, imports, estilos e dependências.
3. Copie o componente para sua aplicação.
4. Adapte-o ao seu sistema de design e teste-o no contexto real.

A maioria dos componentes usa React e TypeScript, mas os requisitos podem variar. Use o caminho de importação e o nome exportado que aparecem no arquivo.
